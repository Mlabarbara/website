MSU Denver Project: Secure Development Environment

Proxmox Ansible Infrastructure as Code

A comprehensive demonstration of setting up a secure development environment using modern DevOps practices.

Prerequisites

  • • Virtual Machine Software (VirtualBox/VMware)
  • • Linux Distribution ISO
  • • Basic networking knowledge
  • • Command line experience

Installation Steps

  1. Download and install prerequisites
  2. Configure network settings
  3. Set up virtual environment
  4. Install required packages
