MSU Denver Project: Secure Development Environment

Proxmox Ansible Docker Kubernetes SSH bash Infrastructure as Code

A comprehensive demonstration of setting up a secure development environment using modern DevOps practices.

Prerequisites

Hardware Requirements

  • • Server Hardware: 64-bit CPU with Intel VT/AMD-V virtualization support
  • • Memory: Minimum 2GB RAM (8GB+ recommended for multiple VMs)
  • • Storage: Minimum 16GB (SSD recommended for better performance)
  • • Network: Compatible network interface card with Internet connectivity

Software Requirements

  • • Proxmox VE: Latest ISO from official website
  • • Development Tools: SSH client, Git, Python 3.x
  • • Web Browser: Modern browser for Proxmox web interface

Network Requirements

  • • Static IP Address: Required for Proxmox host
  • • Port Access: 8006 (Web UI), 22 (SSH), 3128 (Package Management)
  • • DNS Resolution: Proper DNS setup for network connectivity

Required Knowledge

  • • System Administration: Basic Linux command line experience
  • • Networking: Understanding of IP addressing, VLANs, and DNS
  • • DevOps: Familiarity with YAML syntax for Ansible

Installation Process

01

Initial Server Setup

Pre-installation Tasks:

1. Download Proxmox VE

Get the latest version of Proxmox Virtual Environment:

Download Proxmox VE ISO
2. Create Bootable USB

Choose your preferred USB creation tool:

Windows Users: Download Rufus
Mac Users: Download balenaEtcher
Linux Users: ...if you're using Linux I am sure you know what to do. dd will work fine 
sudo dd if=/path/to/proxmox.iso of=/dev/sdX bs=4M status=progress oflag=sync
3. BIOS/UEFI Configuration

Ensure the following settings are enabled in your BIOS/UEFI:

  • Intel Virtualization Technology (VT-x) or AMD-V
  • Intel VT-d or AMD IOMMU (if available)
  • USB Boot Support
  • Legacy USB Support (if using older hardware)
02

Proxmox Installation

Installation Process:

  1. 1

    Boot from USB

    Select the USB drive from boot menu and choose "Install Proxmox VE"

  2. 2

    Drive Configuration

    Select target disk and configure partitioning (default options recommended)

  3. 3

    Network Setup

    Configure hostname, IP address, and gateway

Enable SSH access and configure key-based authentication:

vim /etc/ssh/sshd_config
